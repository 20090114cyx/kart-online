# Kart Prototype — 跑跑手感原型 v0.5

网页版卡丁车竞速的**手感垂直切片**。目标不是堆素材，而是先把「漂移 / 集气 / 小喷 / 连喷」这套手感调到对，再把赛道做成有分叉、隧道、高低差的长赛道。

v0.5 加入**房间码双人联机**：房主开房间、朋友输入 4 位房间码加入，2 个真人 + 2 台 AI 在同一张赛道上比赛。房主客户端跑权威物理，服务器只做房间管理和消息中继；客机本地预测自己的车，远端车用约 100 ms 缓冲插值。此前的**本地双人同屏**、**选图界面**、第二张 3.9 km 的「赤沙峡谷」、AI 自主选支路、90° 直角弯、高架桥和峡谷岩壁全部保留。

## 怎么启动

**双击 `启动游戏.bat`** 就行（会自动装依赖、同时启动房间服务器和 Vite、开浏览器）。

手动启动（两个终端）：

```powershell
cd kart
npm.cmd run server   # 房间服务器，监听 8787
```

```powershell
cd kart
npm.cmd run dev      # Vite，监听 5173，并把 /ws 代理到 8787
```

然后浏览器打开 <http://localhost:5173/>

> 手机真机测试：电脑和手机连同一个 Wi-Fi，用手机浏览器打开 `http://<电脑局域网 IP>:5173/`（`npm.cmd run dev` 已经带 `--host`，会监听局域网）。
> 联机时两台设备都要能访问**同一个 Vite 地址**；Vite 会把 `/ws` 代理到房主电脑上的房间服务器。跨公网需要自己把 5173 / 8787 做端口映射或内网穿透。

> 注意用 `npm.cmd` 而不是 `npm`——你机器的 PowerShell 执行策略挡住了 `npm.ps1`。

## 操作

单人键位如下；双人同屏的 P1 / P2 分键位见下一节。

| 动作 | 键盘（单人 / 菜单） | 手柄 | 手机 |
|---|---|---|---|
| 油门 | `W` / `↑` | RT | 左侧 `▲` |
| 刹车 / 倒车 | `S` / `↓` | LT | 左侧 `▼` |
| 左转 | `A` / `←` | 左摇杆 | 右侧 `◀` |
| 右转 | `D` / `→` | 左摇杆 | 右侧 `▶` |
| 漂移 | 左 `Shift` / `空格` | A / RB | 右下「漂移」键 |
| 回到起点 / 重新比赛 | `R` | — | 结算页「再来一局」 |
| 返回选图 | `Esc` | — | 结算页「选择赛道」 |
| 选图：切换 | `←` / `→` | — | 点卡片 |
| 选图：单人 / 双人 / 联机 | `1` / `2` / `3` | — | 「单人 / 联机」按钮（手机隐藏双人） |
| 选图：开始 | `Enter` | — | 「开始比赛」按钮 |
| 联机：关闭大厅 | `Esc` | — | 「关闭」按钮 |
| 静音 | `M` | — | — |

> 手机端只支持**横屏**：竖屏时会显示「请横屏游玩」并冻结比赛，转回横屏自动继续。
> 点提示里的「全屏横屏」可以尝试全屏并锁定方向（浏览器支持时生效）。
> 操控是「左手油门 / 刹车，右手转向」：`▲` `▼` 在左下，`◀` `▶` 在右下漂移键旁边。
> 漂移键**轻点一下会锁定漂移**，再点一下松漂（触发小喷），这样一根拇指就能边漂边转；按住不放也还是原来的手感。
> 单人模式下左 / 右 `Shift` 都能漂移；切到双人后右 `Shift` 归 P2。

### 双人键位

选图界面切到「双人同屏」后，两个人各用一套键位：

| 动作 | P1（左半屏） | P2（右半屏） |
|---|---|---|
| 油门 | `W` | `↑` |
| 刹车 / 倒车 | `S` | `↓` |
| 左转 | `A` | `←` |
| 右转 | `D` | `→` |
| 漂移 | 左 `Shift` / `空格` | 右 `Shift`（`Numpad0` 备用） |

- **手柄**：第一个连接的手柄给 P1，第二个给 P2。
- **单人模式**：方向键仍然可以控制 P1；切到双人后方向键归 P2。
- **触屏 / 手机**：仍然只支持单人，双人模式在手机端隐藏。

### 怎么漂

1. 先加速到 40 km/h 以上
2. **按住漂移键 + 打方向** → 车尾甩出去，开始漂（P1 左 `Shift` / `空格`，P2 右 `Shift`）
3. 车身和行进方向会形成一个夹角（**滑移角**），左下角「漂移集气」开始涨
4. **松开漂移键** → 如果气够，立刻获得一段小喷加速
5. **松手后 0.45 秒内再按漂移键** → 气量会结转，可以连喷

集气条上那条竖线是**触发小喷的最低门槛**，涨过它再松手才有喷。

### 漂移的转向是独立的一套

漂移不是「抓地转向 × 1.5」，而是**独立的高转速通道**：抓地满速约 63°/s，漂移约 151°/s（2.4 倍）。

所以：

- **按少了拐不过来** —— 急弯必须靠漂移
- **按死了会转过头** —— 按住 4 秒能转过 616°（1.7 圈），得自己收

这个「按多久」的手感就是漂移的核心，别改坏了。

## 两张赛道

开局、完赛和按 `Esc` 都会进入**选图界面**。卡片上显示的是实际采样长度，和游戏里跑的一致。选图界面底部可以在「单人 / 双人同屏 / 联机」之间切换（选图时按键盘 `1` / `2` / `3`，对应 `Digit1` / `Digit2` / `Digit3`，也可以切换）；手机端只显示「单人 / 联机」。

### 翡翠森林（★☆☆，3 圈）

主环 **1843.4 m**，主路宽 22 m；一条内场支路「林间捷径」**495.9 m**，比主环对应路段短 **10.6%**。

| 位置 | 是什么 | 怎么走 |
|---|---|---|
| t≈0.60 分叉口 | 主环 / 内场支路 | 青色箭头 = 内场支路（左），橙色箭头 = 主环（右） |
| t≈0.138–0.188 隧道 | 92.9 m 长隧道 | 进洞前有指示牌，洞里靠顶灯 |
| 两处加速带 | 支路 u≈0.36、主路 t≈0.205 | 压上去立刻 +3.2 m/s，并进入 1.2~1.5 s 加速 |

内场支路连续急弯 + 一个跳台，不是白送的捷径——想赚时间得靠漂移，撞墙就亏。

### 赤沙峡谷（★★★，2 圈）

主环 **3869.5 m**，主路宽 24 m；三条支路各有性格：

| 支路 | 长度 | 特点 |
|---|---|---|
| 北境捷径 | 465.0 m | 长度基本持平，1 个加速带 + 跳台，风险低 |
| 绿洲快线 | 383.8 m | 比主路短 0.9%，2 个加速带，中段有沙地减速带 |
| 峡谷险道 | 551.3 m | 比主路长 1.6%，2 个加速带，最窄、风险最高 |

- **3 个 90° 直角弯**（t≈0.418 / 0.448 / 0.476），必须提前刹车或漂移
- **116.4 m 隧道**（t≈0.555–0.585）
- **2 段高架桥**（t≈0.225–0.285、0.455–0.515），桥墩和横梁都在路面以下
- **2 段峡谷岩壁**（t≈0.62–0.72、0.90–0.97），五层砂岩色带 + 风化起伏
- 主路 3 处加速带 + 支路 5 处加速带，共 **8 处**；主路还有 2 处沙地减速带

分叉 / 汇合处都做了地面高度平滑混合，车轮不会在接缝处被台阶弹飞；护栏在分出口和汇入口留了缺口。高架桥段不铺路堤，否则整座桥会被土坡埋住。

## 高低差 / 跳台

赛道不再是纯平面了。两张赛道共用同一套地形系统；下表是翡翠森林的参数，赤沙峡谷的山丘最高到 8 m，另外还有高架桥和峡谷。

| | 位置 | 高度 | 效果 |
|---|---|---|---|
| 缓坡山丘 | t≈0.14 / 0.36 / 0.58 / 0.90 | 4.5 / 6.5 / 3.0 / 5.0 m | 上坡掉速、下坡加速，坡顶会轻微浮空 |
| **主路跳台** | t≈0.28 / 0.62 | 1.2 / 1.8 m | 冲过唇口直接起飞，滞空 0.7~1.2 s |
| **支路跳台** | 各支路 u≈0.45~0.55 | 1.5~2.0 m | 同上，落点更窄 |

跳台上坡面刷了**黄黑箭头**，追尾视角一眼能认出来。

物理是统一的抛体积分：每一步先把车当抛体走一步，再判断它有没有穿到地面以下。穿下去了就贴地（垂直速度改成地面爬升速度），没穿下去就是腾空。所以：

- **上坡时地面顶着你** —— 贴地，但会掉速
- **越过唇口时地面下坠得比自由落体还快** —— 车自然带着上坡积累的垂直速度飞出去，不需要任何「起跳判定」
- **落地冲击**按垂直速度算，硬的落地会掉 3% 速度 + 镜头震一下 + 扬尘

空中转向被限制在 40%（`空中转向` 可调），所以跳台不是全自动的 —— 飞出去之后要靠落点前的微调。

**腾空时不集气**：按住漂移飞过跳台不会白嫖一管气，落地后如果还按着，漂移会接着走。坡度上漂移的集气速率和集气上限跟平地一样。

## AI 对手 / 比赛

现在是 **4 台车**的完整比赛，圈数随赛道变化（森林 3 圈 / 峡谷 2 圈）。单人模式是「你 + 3 台 AI」；双人同屏是「P1 + P2 + 蓝影 + 青锋」，紫电不参赛。

| 车手 | 车身 | 性格 |
|---|---|---|
| P1 | 红 | 玩家 1，WASD + 左 Shift / 空格 |
| P2 | 橙 | 玩家 2，方向键 + 右 Shift（仅双人同屏） |
| 蓝影 | 蓝 | 最快，走线最贴弯心，敢赌支路 |
| 青锋 | 绿 | 中等，保守，只走最稳的支路 |
| 紫电 | 紫 | 稍慢，爱抄近路，适合当第一个要超越的目标（仅单人） |

- **发车**：两排两列。单人时你在第二排右侧，前面两台 AI；双人时蓝影 / 青锋第一排，P1 / P2 第二排。
- **倒计时**：3 → 2 → 1 → GO!，倒计时期间油门被锁住，不会抢跑。
- **名次**：每个玩家面板的顶部中央实时显示第几 / 共几台。
- **完赛**：跑完该赛道的圈数后，单人直接弹结算（名次 + 总用时），可以「再来一局」或回「选择赛道」；双人时先完赛的玩家由 AI 接管巡航，两人都完赛后弹出总结算。
- 车顶有名字标签，隔着弯也能认出前面是谁。

AI **不走另一套物理**：它和玩家一样调用 `Kart.step()`，同样会漂移、集气、小喷、被跳台弹飞、撞护栏。区别只有三个：

1. **走线**：中心线向弯心偏移，形成一条简单的赛车线（直道回中间，弯心贴内侧）。
2. **会自己选支路**：在分叉口前约 120 m 评估「长度收益 + 加速带 − 风险 + 落后追赶」，再按车手性格的阈值决定进不进。
3. **橡皮筋**：领先玩家太多时主动收油等人，落后时稍微追一下。强度可以在调参面板「AI 对手」里调；调到 0 就是纯实力对抗。

支路性格：

| 车手 | 支路倾向 | 实测（峡谷 2 圈，单人） |
|---|---|---|
| 蓝影 | 0.72，敢赌 | 三条支路每圈都进 |
| 青锋 | 0.35，保守 | 只进最稳的「绿洲快线」 |
| 紫电 | 0.88，爱抄近路 | 三条支路每圈都进 |

双人模式里紫电不参赛，蓝影和青锋的支路行为不变。

AI 在支路终点前（u>0.955）切回主路，不会在汇合口被夹住；切回后有 1.2 s 冷却，避免在分叉口反复横跳。

AI 也会互相超车、避让前车、被撞歪后自己回正；卡在墙上超过 1.3 秒会倒车自救。

> 想先自己练手，把「AI 速度」拉到 0.55 左右，它们就会明显放慢。

## 本地双人同屏

一台电脑，左右各一半：2 个真人 + 2 台 AI 在同一张赛道上跑。两个人用的是同一套 `Kart.step()` 物理、同一套赛道碰撞和加速带，不存在「副驾驶简化物理」。

### 比赛规则

- **发车 4 台车**：P1、P2、蓝影、青锋；紫电在双人模式里不参赛。
- **各自计时**：P1 / P2 的圈速、最佳圈速、名次和完赛结算完全独立。
- **先完赛的人交给 AI**：第一个跑完圈数的玩家由 AI 接管，继续沿赛道巡航；另一位继续比赛。两人都完赛后弹出总结算。
- **左右分屏**：左右各占一半，每个视口有自己的追尾镜头、HUD、小地图和冲刺后处理；中间有一条分界线。
- **手机 / 触屏**：只开放单人，双人按钮在手机端隐藏。

### 实现要点

- `Input` 增加 P2 通道（`throttle2` / `brake2` / `steer2` / `drift2`）；单人时原有字段继续给 P1，双人时方向键和第二个手柄映射到 P2。
- `Hud` 改成 **root-scoped**：构造函数接收一个面板根节点，一套实例只抓取自己面板里的 `data-hud` 元素；`#hudP1` / `#hudP2` 各一个实例。
- `PostFX.renderSplit()`：每个视口先把场景渲进**同一张 RenderTarget** 的对应区域（viewport + scissor），再逐视口跑同一个后处理 shader，不复制 target。
- **性能**：分屏会把场景渲染两次（每个视口一次），后处理也跑两次；动态分辨率仍然生效，按实测帧时间自动缩放。

## 房间码双人联机

选图界面点「联机」打开大厅：

1. **房主**：填名字 → 点「创建房间」→ 把 4 位房间码发给朋友 → 点「开始比赛」。
2. **客机**：填名字和房间码 → 点「加入房间」→ 等房主开始。
3. 房间最多 2 个真人；空位由 AI 补齐，始终 4 台车。两人都在时是「房主 + 客机 + 蓝影 + 青锋」。

### 分工

- **房主客户端跑完整物理**：4 台车的 `Kart.step()`、赛道碰撞、加速带、圈数、完赛判定都在房主这边。
- **服务器只做房间管理和消息中继**：创建 / 加入 / 离开房间、转发输入和快照；它不跑游戏物理，也不判定圈数。
- **房主按 30 Hz 广播快照**：4 台车的位置、朝向、速度、集气、漂移、圈数、圈速、完赛状态。
- **客机按 30 Hz 发输入**：油门 / 刹车 / 转向 / 漂移，房主把它套到橙色车上。
- **客机本地预测自己的车**：按键立刻有反应，不会被网络延迟拖住；收到最新权威快照后平滑回拉。
- **远端车约 100 ms 缓冲插值**：客机看到房主的车会晚约 0.1 秒，但连续顺滑，不会一顿一顿。

### 比赛规则

- **发车顺序固定**：房主红车、客机橙色车、蓝影、青锋；快照按这个顺序一一对应。
- **各自计时**：圈速、最佳圈速、名次、完赛结算都以房主为准，客机只显示。
- **先完赛的真人交给 AI**：和本地双人一样，先跑完的人由 AI 接管巡航，另一位继续跑。
- **所有真人完赛才结算**：两人都完成后弹出总结算；客机也会同步看到结算面板。
- **客机掉线**：房主让 AI 接管橙色车，比赛继续；重开后橙色车仍是 AI。
- **房主掉线 / 离开**：房间关闭，客机回到联机大厅。
- **重开**：房主按 `R` 或点「再来一局」直接重开并广播；客机按 `R` / 点「再来一局」是向房主发重开请求。
- **手机也能联机**：手机端保留「联机」入口，横屏下大厅卡片会限高并内部滚动。

### 已知限制

- 没有专用服务器：房主电脑同时跑物理 + 渲染，客机看到远端车约 100 ms 延迟；同 Wi-Fi 下最稳。
- 跨公网需要端口映射 / 内网穿透；当前服务器没有账号、匹配、断线重连和反作弊。
- 客机预测是「本地先跑、快照回拉」，撞车和网络抖动时仍可能出现小幅修正。

## 调参面板（桌面端右上角，点「手感调参」展开）

所有手感参数都能实时拖，**拖完立刻生效，不用刷新**。手机端会自动隐藏这个面板，避免挡住 HUD。

| 你感觉 | 该调哪个 |
|---|---|
| 转向太迟钝 / 太贼 | 转向 → 最大转向角速度、转向响应 |
| 车太滑 / 太黏 | 抓地 → 正常抓地（数值越大越黏） |
| 漂移角度太小 / 太大 | 抓地 → 漂移抓地（**越小滑得越横**） |
| 漂移转不过急弯 | 抓地 → **漂移最大转向**（调大） |
| 漂移太容易转过头 | 抓地 → 漂移最大转向（调小）、漂移高速衰减（调小） |
| 漂移掉速太多 / 太少 | 抓地 → 漂移掉速 |
| 小喷太短 / 太长 | 小喷 → 基础时长、每格气加时长 |
| 小喷那一下不够爽 | 小喷 → 瞬间冲量、持续加速 |
| 连喷接不上 | 小喷 → 衔接窗口、气量结转 |
| 车太轻飘 / 太笨重 | 镜头 → 跟随刚度、距离、高度 |
| 冲刺镜头晃得太厉害 | 镜头 → 冲刺震动 |
| 跳起来太飘 / 太重 | 高低差 → **重力** |
| 上坡掉速太多 | 高低差 → 坡度影响（调小） |
| 空中不好调整方向 | 高低差 → 空中转向（调大） |
| 落地太震 / 没感觉 | 高低差 → 落地冲击 |

「操作 → 复制当前参数」可以把当前数值导出成 JSON，发给我就能固化成新的默认值。

## 调试

页面里有个全局对象 `window.__game`，浏览器控制台里能直接摸到 `kart` / `racers` / `track` / `cam` / `renderer`。

`window.__game.tick(n, dt)` 可以手动推进 n 帧（默认 1/60 秒一帧，会完整跑逻辑 + 渲染）。**窗口失焦时浏览器会把 `requestAnimationFrame` 节流到 1~2 fps**，所以自动化测试必须走这个接口，不能靠等待真实时间。

- `__game.racers`：4 台车的数组，`racers[0]` 是 P1；双人时 `racers[1]` 是 P2；联机时固定 `[player, player2, 蓝影, 青锋]`。
- `__game.setMode(1 | 2 | 3)` / `__game.getTwoPlayer()`：切换 / 查询单人、双人、联机大厅；双人时 `__game.player2`、`__game.cam2`、`__game.hud2`、`__game.minimap2` 可用。
- `__game.net`：联机客户端，含 `inRoom` / `code` / `isHost` / `players` / `roomState`。
- `__game.getRoomCode()` / `__game.getOnlinePlayers()` / `__game.getLastSnapshot()`：当前房间码、玩家列表、最近一帧权威快照。
- `__game.online` / `__game.onlineHost` / `__game.localRacer`：是否在联机比赛、是不是房主、本机控制哪台车。
- `__game.resetRace()`：重开一局；`__game.restartRace()` 在联机里会走房主广播 / 客机请求。
- `__game.getRaceState()`：`menu` / `countdown` / `racing` / `finished`。
- `__game.getTrackId()`：当前赛道 `forest` / `canyon`。
- `__game.selectTrack(i)` / `__game.startRace()`：选图 / 开始比赛；`__game.openTrackMenu()` 打开选图界面。
- `__game.TRACK_DEFS`：两条赛道的原始定义。
- `__game.track.main` / `__game.track.branches`：主路和所有支路的 `TrackPath`，含 `length` / `points` / `halfWidths` / `nearestIndex()` / `progressAt()`。
- `__game.track.layout.branches`：每条支路的 `lengthGain` / `maxCurvature` / `risk` / `boostPadCount`，调 AI 选路时看这个。
- 自动化跑圈时，可以临时 `__game.postfx.render = () => {}`（双人分屏时同时置空 `renderSplit`），模拟速度会快一个数量级；测完记得还原。
- 手机布局预览：打开 <http://localhost:5173/mobile-test.html>（844×390 横屏 iframe），或者给游戏地址加 `?touch=1` 强制显示触屏控件。
